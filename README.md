# Chatbot Project

A simple chatbot project built with Python.

> 🇨🇳 中文：一个使用 Python 构建的简单聊天机器人项目。

## Features

- Natural language processing
- Configurable memory module
- LLM integration

> 🇨🇳 中文：
> - 自然语言处理
> - 可配置的记忆模块
> - 大语言模型集成

## Installation

1. Clone the repository.
2. Install dependencies: `pip install -r requirements.txt`

> 🇨🇳 中文：
> 1. 克隆仓库。
> 2. 安装依赖：`pip install -r requirements.txt`

## Configuration

Edit `config.py` to set your API keys and model parameters.

> 🇨🇳 中文：编辑 `config.py` 设置 API 密钥和模型参数。

## Usage

Run the chatbot:

```
python chatbot.py
```

> 🇨🇳 中文：运行聊天机器人：

```
python chatbot.py
```

## File Structure

- `chatbot.py`: Main chatbot script
- `chat_chain.py`: Chain-of-thought processing
- `config.py`: Configuration settings
- `memory.py`: Memory management
- `llm/`: LLM module directory
- `requirements.txt`: Python dependencies

> 🇨🇳 中文：
> - `chatbot.py`: 主聊天脚本
> - `chat_chain.py`: 思维链处理
